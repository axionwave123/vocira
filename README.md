# VOCIRA

**One name, many voices, endless connections.**

Premium AI-powered communication and meeting intelligence platform.

## Engines

- **VoiceBridge** — Real-time two-way voice translation
- **Live** — Original and translated live subtitles
- **Brain** — AI meeting intelligence, summaries, decisions, tasks, risks & fishbone analysis

## Tech

- React + TypeScript + Vite
- React Router
- Modular CSS with design tokens
- Progressive Web App ready

## Getting Started

```bash
npm install
npm run dev
```
